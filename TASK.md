Creating and Searching Vacancies on Dicoding Jobs
Dicoding’s vision is to become the leading tech education platform by driving greater access to digital literacy for everyone. We have a mission to accelerate Indonesia’s transition to a digital world through life-transforming tech education.
Academy, an online learning platform is one of our flagship products that become our main business. But apart from that, we also have Challenges, Events, and Jobs that complement the student's learning journey to become a developer.
In this technical exercise stage, we challenge you to transform a use case in Dicoding Jobs into a real solution. We will assess your skills in several aspects such as problem solving, technical skills in programming, as well as accuracy in UI design implementation.
The Exercise
To prove your skills have met our needs, you will build a simple job vacancy system using:
Backend: Laravel (PHP)
Frontend: Next.js
Database: MySQL (recommended), or any SQL database


The system must support the following user stories:
💼 As a Recruiter, I want to be able to create a new vacancy, so that my vacancy can be listed on the Dicoding Jobs platform.
🔍 As a Job Seeker, I want to search for jobs by title, so that I can find the job that I want.

You got help from our Product Designer!
You can use the following art from our Product Designer to do the exercise above. Of course, your creativity is not limited to this.

Figma


By completing these exercises, you will be evaluated based on several aspects. The evaluation criteria and instructions for each aspect are provided in rubrics below. Please follow the instructions accordingly.

Backend Development using Laravel (40 pts)
Build a RESTful API using Laravel with the following feature:

Mandatory Features
Create Vacancy
API endpoint to store new job vacancies into the database.
List Vacancies
Return all available vacancies.
Detail Vacancy
Return details of a specific vacancy by ID.

Optional Features
Update Vacancy
Modify an existing vacancy.
Delete Vacancy
Remove a vacancy from the database.

Additional Notes
Follow Laravel best practices.
Database schema can follow the Figma design or your own improved structure.
Apply basic request validation.

Frontend (Next.js) + API Integration (20 pts)
Build a RESTful API using Laravel with the following feature:
Fetch vacancy data from your Laravel backend.
Implement a job search feature by title.
TanStack Query is encouraged for maximum score but not mandatory.

UI and Styling (20 pts)
Requirement
Create reusable Job Card components.
Design must follow the Figma references closely.
You may use CSS Modules, Tailwind, styled-components, or any preferred styling approach.

Testing (Unit, Integration, End-to-End) (40 pts)

Backend (Laravel)
You must implement:
Unit Test (vacancy model logic, validation, or helper functions)
Integration Test (API endpoints that interact with DB and validate response)

Frontend (Next.js)
You must implement:
End-to-end using Playwright
User opens the vacancies list page
User searches a job by title
User views vacancy details

Submission Instructions
Once you have completed the technical assessment, please follow these steps:
Upload your full solution (frontend + backend + tests) to a public GitHub repository.
Your repository must include:
A clear README
Setup instructions
How to run the Laravel backend
How to run the Next.js frontend
How to run all tests (unit, integration, and end-to-end)
Submit your GitHub repository link through the Google Form provided in your recruitment email.

Please ensure the link is publicly accessible without requiring additional permissions.

Conclusion
In conclusion, this technical exercise offers you an opportunity to demonstrate your problem-solving skills, programming abilities, and accuracy in implementing UI design. By completing the exercise, you will be evaluated based on your ability to integrate databases, implement search features, style the application, and conduct testing. The purpose of this exercise is to assess your suitability for working on a real solution at Dicoding.
